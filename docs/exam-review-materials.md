# 考试讲评资料包（第一版）

考试详情页提供“考试讲评资料”。教师选择班级、课堂时长和展示内容后，系统保存一份固定版本的原题、答案、统计与逐题讲评草稿。教师可修改知识点、解题思路、选项辨析、可能错因、已确认错因、课堂检查及讲课备注，设置纳入导出、详讲/略讲和核对状态，然后下载自包含 ZIP，交给办公助手制作演示文稿。

第一版交付备课资料及逐页建议，尚不直接生成 PPTX。新考试发布作答后自动建立默认草稿；历史考试及尚未发布的考试可手动生成。未发布、缺失与待复核数据保持其状态，不阻断草稿整理，也不被当成零分或空白。

## 使用流程

1. 在考试详情的“考试讲评资料”选择班级与课堂时长，按需展开“课堂展示内容”。
2. 点击“生成讲评资料草稿”，进入逐题编辑页。
3. 已配置学校大模型且本题答案已确认时，后台按题生成讲评；进度、失败和单题重试均在页面显示。图文题需要模型支持图片输入。未配置模型或参考答案未确认时，保留原解析与标签作为可编辑草稿。
4. 核对原题、参考答案和统计，编辑讲评内容，选择详略与纳入范围，保存本题。教师确认只代表讲评内容核对，不修改原题答案审核状态。
5. 下载资料包，解压后打开“预览.html”核对图文公式，将完整资料包及“制作说明.md”交给办公助手。未保存的页面编辑会阻止下载，避免漏带改动。
6. 更正作答、题目版本、班级范围或已有错因记录后，旧资料显示过期提示。返回考试生成新版；旧版本与教师编辑保留。

页面暂存未保存输入于当前浏览器标签页的 sessionStorage；服务端采用逐题版本号防止覆盖另一页面的修改。发生版本冲突时可对照服务器内容，保留自己改过的字段或载入服务器版本，再核对保存。

## 统计口径

页面与资料包共用 `exam_statistics.question_statistics`，使用本次考试参与记录中状态为 `present` 的学生，以及经复核和更正后的有效首次作答。重做不参与。

- 正确率：正确人数 / 已确认结果人数（包含确认空白）。缺失和待复核不计入。
- 选项选择率：选择该选项人数 / 已确认且选项可辨识的作答人数（包含确认空白）。仅得分、选项无效等情况列为选项未知。
- 多选题同时保留完整组合；各选项选择率之和可以超过 100%。
- 得分率：有有效得分及满分记录的得分之和 / 对应满分之和。不根据选项猜测漏选给分规则。
- 分班与合计均从人数重新计算；空分母为 `null`，显示“暂无有效数据”或“—”。
- 得分读取有效判定关联的证据，不使用可能尚未生效的最新证据。

考试页的选项分布原先按实到人数计算；本次改为上述口径。待确认、缺失与选项未知的分类比例另标“占实到”，用于展示覆盖情况。

## 内容来源与边界

- 原题从考试快照绑定的内容版本或已生效的历史更正读取，不跟随题库当前版本。老格式缺少快照解析时不从当前题库补造。
- 原题、选项图与答案图由内容资产及历史题图提供；固定 SHA-256，下载时验证版本、学校和引用关系。缺失图片不会被静默省略。
- 参考答案未确认时不自动生成解析；资料仍明确保留待核对状态。
- 教师错因标签按当前有效错题汇总，导出仅含标签和人数，不导出可能带姓名的自由备注。
- 学生自述只取当前有效、属于本次考试的最新事件；取消记录生效。整题自述标明整题范围，不自动归因到每个小问。多次来源混合的事件不冒充本次考试的证据。
- AI 只收到题目、已确认答案、考试标签和必要题图，不收到学生身份、答卷、统计或错因人数。可能错因与事实分开，教师可补充已确认的原因及依据。
- 后台生成与重试不会覆盖教师修改的字段；若生成了尚未核对的新字段，会撤销该题的讲评核对标记。

## 导出协议

ZIP 包含：

| 文件 | 用途 |
| --- | --- |
| `制作说明.md` | 供办公助手执行的制作约束与交付要求 |
| `讲评总稿.md` | 按展示设置组织的完整讲评总稿 |
| `逐题数据.json` | 固定原题、答案、统计、讲评内容、字段来源及版本 |
| `逐页安排.json` | 题目页、答案统计页、思路页、演讲备注、建议用时 |
| `统计表.csv` | 分班与合计的原始人数、分母及比例 |
| `questions/` | 每题独立 Markdown，相对路径引用图片 |
| `assets/` | 去重后的原题图片 |
| `预览.html`、`vendor/katex/` | 无需联网的图文公式预览 |
| `manifest.json` | `hsp-exam-review-v1`、来源指纹、范围、草稿/核对状态、过期状态、文件与图片校验值 |

源 JSON 始终含教师参考答案；“不展示答案”等设置约束课堂内容和逐页计划，不是保密导出。资料包不包含学生姓名、学号、身份映射和答题卡。教师自行输入的内容保留原文。

## 数据与接口

增量建表：`exam_review_packages`、`exam_review_items`；`app_schema_migrations` 中 `exam_review=1`。不重写考试、作答、证据、判定、首次答案、题目快照和重做记录。

教师会话操作均校验学校及考试权限；写接口要求同源请求。

- `POST /api/learning/review-create`：`assessment_id`、`request_key`、可选 `class_ids`、`minutes` 及 `show_*` 开关。重复请求幂等，不同内容复用同一标识返回冲突。
- `POST /api/learning/review-status`：`package_id`，返回逐题进度和资料过期状态。
- `POST /api/learning/review-save`：`package_id`、`item_id`、`revision`、`content`（仅修改字段）、`included`、`emphasis`、`reviewed`。
- `POST /api/learning/review-retry`：`package_id`、`item_id`，只重试失败或原资料草稿题。
- `GET /api/exam-review/{id}`：资料详情。
- `GET /api/exam-review/{id}/export.zip`：打包导出。
- `GET /api/exam-review/{id}/assets/{asset_id}?item_id=...`：经权限及校验值验证的原题图片。
- `GET /exam-review?id=...`：教师编辑页。

复用现有 `document_worker` 后台服务。生成使用120秒租约和写回令牌，进程中断可恢复；连续3次租约过期转失败，人工可逐题重试。模型调用有预算检查、60秒超时、输出结构验证和用量台账，错误记录不保留上游原文或密钥。自动创建讲评失败不回滚已经发布的考试，页面提示可重新生成。

## 验证入口

`python -m unittest tests.test_exam_review tests.test_exam_statistics tests.test_response_workflow tests.test_exam_workflow`

覆盖统计分母、多选、得分证据、缺失与待复核、分班合并、身份与学校隔离、同源要求、幂等及版本冲突、旧稿保留、匿名离线包及图片校验、后台租约与教师覆盖保护、未确认答案、模型输入与输出边界、自动建稿与考试发布隔离。

发布仍执行 `REQUIRE_REMOTE_HEAD_MATCH=1 bash scripts/hsp_release_check.sh`，并检查远端页面、资源与新增功能路径。
