# 考试正确率驱动的题目难度

难度按本校同一题目在所有已发布考试中的有效首次作答累计计算：正确次数 / 已确认作答次数。每场考试每名学生计一次，不对各场考试的百分比求平均。

| 难度 | 正确率 |
| --- | --- |
| 挑战 | 0% ≤ 正确率 < 30% |
| 拔高 | 30% ≤ 正确率 < 50% |
| 巩固 | 50% ≤ 正确率 < 70% |
| 基础 | 70% ≤ 正确率 < 90% |
| 送分 | 90% ≤ 正确率 ≤ 100% |
| 未分级 | 没有符合统计口径的作答记录 |

- 只统计实到、已确认的考试作答；空白计入分母，缺失、待确认、不纳入和缺考不计入。
- 学习练习、独立验证等重做不参与题目难度计算。教师更正后按当前有效考试结果计算，原始作答不改写。
- 同一题目不同考试版本按题目 ID 累计，题干、标准答案及标签仍使用原有快照机制。
- 不足一次有效作答时显示未分级；有一次即可分级，同时显示正确率和正确/总次数。
- 小问分别分级；整题展示列出全部小问的等级，不生成混合等级。
- 实时派生，不写回原有手工 `difficulty` 字段，不修改历史考试和学生作答。

题库接口的 question 与 units 返回 `difficulty_stats`（label、correct_count、response_count、correct_rate）；整题列表返回 difficulty_units。题库、组卷预览、考试、学生错题、练习记录、标签关联题目及错题 HTML/PDF 导出共用统计口径。

验证：`python -m unittest tests.test_question_difficulty tests.test_learning tests.test_question_bank tests.test_exam_statistics`。
