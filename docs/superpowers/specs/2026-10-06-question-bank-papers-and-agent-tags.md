# 题库、导入试卷、考试和 Agent 标签接口

## 教师流程

1. 现有 Word/PDF 导入与答案复核继续使用；题目文件上传增加入库方式：整张试卷或零散题目。答案文件仍关联原题文档。
2. 正式入库后跳到题库并筛选当前导入批次。整卷模式在同一事务中保存可重复使用的 `papers` / `paper_questions`；零散模式只入题库。分次确认入库会按原题及小问顺序扩展同一套试卷。
3. 题库支持批次、试卷、题干和题号筛选、分页、跨页全选当前范围、展开完整题目、版本化编辑正文/选项/答案/解析，以及逐小问标签管理。
4. AI 从管理员已启用的大模型 API 生成三类候选。新导入页面不自动消耗模型调用；教师在题库明确点击触发。未标注题和重新生成所选题分别提供入口。
5. AI 建议显示依据，可以逐题填入后修改并保存，也可以采用所选建议批量保存。后台只生成候选，不覆盖教师或 Agent 保存的正式标签。页面刷新后可从任务记录恢复仍有效的候选。
6. 新建考试可直接选择保存的试卷，也可继续从教师工作台选题组卷。可先保存未标注的试卷；创建考试需要逐小问确认标签并至少一个知识点。能力/素养没有充分依据时允许明确保存为空。
7. 题库修改生成新的内容版本。已有考试的题目版本、标签快照、学生首次作答和判定保持原样。本次范围不包含已发布考试的历史标签重算。

## 实现边界

- 复用现有题库、试卷、标签库、候选、持久任务队列和审计。
- 新增 `question_bank_imports` 保存入库方式与试卷关联、`question_tag_revisions` 提供乐观锁、`question_bank_agent_tokens` 提供学校和账号范围内的限期凭证。
- 所有三类标签保存通过同一验证路径：每类最多三个、不能重复、必须属于当前学校启用的标签库。批量保存为单个事务，任何条目失败整批回滚。
- 标签修改要求题目 `question_version` 和标签 `expected_revision` 一致，冲突返回 409。内容修改同时校验整题 revision，保留小问稳定 ID、题型、原图和历史快照。
- 题库内容编辑暂不改变小问数量/题型；带自定义判定规则的题目修改答案时要求同步规则，避免静默改变判分语义。
- 旧导入 API 默认保留原自动标注行为；新页面显式使用 `tagging_policy=question_bank`。旧自动任务也保护已经人工保存的标签。

## Agent 接入

在题库的“外部 Agent 标签接口”创建凭证，绑定当前有效教师/管理员账号与学校，有效期 1—90 天，可撤销。数据库仅存 SHA-256 摘要；明文只在创建响应中显示一次，不进入审计。退出或撤销学校/账号权限后不能继续操作。

使用部署入口的 `/api/question-bank/`，代理环境带 `/physics` 前缀。认证头为 `Authorization: Bearer <token>`，POST 为 `application/json`。

- `GET library?batch_id=...&paper_id=...&search=...&offset=...`：批次、试卷、每页 30 道大题、当前筛选全部小题 ID。
- `GET taxonomy`：可用知识点/能力/素养 ID 与名称。
- `GET question?id=...`：完整文档、答案解析、各小问 ID 和标签/题目版本。
- `GET assets/<asset_id>?question_id=...`：仅本校题目当前版本引用的图片。
- `POST tags`：原子批量修改标签，一次最多 500 道小题，每类可为空。

```json
{"entries":[{"question_id":"q-example","question_version":1,"expected_revision":0,"knowledge":["knowledge-id"],"ability":[],"literacy":[]}]}
```

返回 `items` 包含新标签版本。409 需重新读取并判断；403 表示凭证或权限失效；404 表示资源不可访问。Agent 凭证不能调用内置模型、编辑题目、管理凭证、创建考试或读取学生数据。教师页面使用同一标签写入接口，但采用登录会话和同源校验。

在线说明位于 `/question-bank/agent-guide`。

## 验证与发布

- 新增端到端测试覆盖两种入库、批次原题顺序、AI候选并发保护、批量原子性、学校隔离、凭证摘要/撤销/过期、图片权限、编辑版本与历史考试快照。
- 浏览器验证桌面及 390px 页面、人工保存、内容编辑、保存试卷及选择试卷创建考试。
- 发布执行 `REQUIRE_REMOTE_HEAD_MATCH=1 bash scripts/hsp_release_check.sh`，实际结果另行记录。未配置真实大模型时，仅能确认提示和队列逻辑，不能声称真实模型生成已验证。

## 题库筛选与完整题文升级（2026-10-06）

题库卡片直接显示完整题干、选项和小问，不再截断预览。调用共享安全渲染器的紧凑布局：公共题干位于上方，选项或小问位于下方左侧，题干和小问的插图集中到下方右侧约三分之一区域，保持图片比例并自适应限高。选项字母与小问编号和首段正文同行；参考答案、编辑和标签表单按需展开。

左侧标签树包含知识点、能力和核心素养，以 parent_id 分层，可展开、收起、选择。选择父节点包含启用子节点。标签命中任一小问时展示并选择完整大题。筛选可与批次、试卷、搜索、题型组合。分页按大题计数，可切换 10/20/50，默认 20；全选始终涵盖当前筛选全部分页。

`questions.bank_type` 保存整题分类（单选、多选、实验、解答、填空、待确认），与小问判分使用的 `question_type` 分开。数据库功能版本 `question_bank_filters=16` 首次升级按现有完整文档分类；后续启动不重置教师修改。导入复核增加“题库整题类型”，保存到文档 bank_type 并随入库写入所有小问。题库提供教师专用 `POST /api/question-bank/type`，检查题目版本后统一修改整题全部小问分类，保留历史考试快照；Agent 凭证仍仅能修改标签。

原卷标题“1-7为单选，8-10为多选”在旧解析中被整段误判为多选。拆题器现按题号区间继承对应选择题类型，并为实验章节保留整题类型。现有题型补录需根据原卷说明执行一次，不按答案数量猜测。

本轮标注覆盖当前授权学校 15 道大题、23 道小题，采用启用的教材知识节点、能力与核心素养，使用 Agent tags API 原子保存并保留审计。凭证不进入代码或文档。
