## 1. 结论与范围

决策：**本地化重建**。先交付错题页中的轻量自我诊断；第一版保存现有知识 / 能力标签及题目版本引用；待证据质量得到验证后，再由关联图谱汇总跨题困难。用户不需要先进入星图才能诊断，也不必等待图谱关系全部建好。

## 4. 学生流程：通常两次操作，最多三次

首次打开题目时，在题干与首次作答依据附近显示一张不遮挡内容的小卡：“先找找这道题卡在哪”。普通诊断目标用时 30—60 秒；这是试点目标，不是已验证结果。不显示倒计时，不强制完成，随时可以进入正常复习或查看解析。

### 操作一：选择自己最先卡住的位置

三个主要入口：

- 不知道从哪里下手。
- 有思路，但中间接不下去。
- 做完了，却不知道哪里出了错。

“现在会了 / 记不清 / 暂时跳过”作为简短退出入口。没有选择不等于不会；空白作答还可能是没有做到、时间不足或漏答，这些属于作答情境，不直接变成能力弱点。

不要求学生判断 D2/D3 等术语，不用“粗心”作为最终解释。首次打开时的回忆是当前回顾，单独注明来源。

### 操作二：只检查一个关键动作

根据题目经审核的诊断卡和学生选择，呈现一道可在一次点击或可选短句中完成的微任务，例如：

- 从题中指出决定约束的一条条件。
- 选出当前适用的研究对象或规律。
- 判断下一步先求哪个量。
- 在两种受力图 / 列式中找差异。

不要求重新输入整套解题过程。每次只检查一个教学假设；微任务本身提供了什么信息也必须记录。学生选“说不清”与错误答案分开保存。

系统直接呈现一句“本次发现”与一个下一步动作，不增加强制确认页。允许学生点“和我的情况不符”更正，原始自述与更正同时保留。

### 可选操作三：一次提示后重试

只有仍未推进且学生主动请求帮助时，显示一个弱提示，并让其重试同一个微任务。上限到此结束，不继续 H1—H5 连续追问。失败或仍说不清时给出“暂未定位”，转向对应解析片段或教师帮助。

弱提示后的表现可说明“在此帮助下能够完成”，不证明该提示对应的唯一认知缺陷。若不需要帮助，则保持在第二次操作结束。

### 示例：明确约束的最高点问题

情境限定为质点沿固定、竖直、光滑圆形轨道内侧运动，题目明确“最高点恰好不脱离轨道”。

- 学生自述：“有思路，但中间接不下去。”
- 微任务：“这里‘恰好不脱离’首先对应哪个边界条件？”选择 `N=0`、`v=0`、`a=0` 或“说不清”。
- 若答对：反馈“你这次识别出了接触临界条件；仅凭这一项，还不能确定原题为什么出错。”可继续原题或查看下一步连接，不强行归因为知识组织。
- 若答错：仅记录该条件理解需要核对；可选提示“接触力不能把小球拉向轨道，想想刚要失去接触时发生什么”，再试一次。
- 提示后答对：反馈“在提醒下，你能把接触条件转成边界条件。下次先判断约束，再写方程。”这不是独立掌握证据。

题库试做中已经看过答案再加入的错题，入口改为“看过讲解后的反思”；不能再标为答案揭示前诊断。无法得知是否看过外部解析时，帮助暴露状态为“不明”。

## 5. 如何与学科图谱连接

区分三个对象：

1. **学科关系图**：共享知识、能力、素养与教学关系，面向所有学生。
2. **题目诊断卡**：一道题的关键动作、多个可接受思路、微任务与提示，绑定具体题目内容版本。
3. **个人诊断证据**：学生自述、微任务答案、提示暴露、当前结果、可修改的候选解释。

题目诊断动作通过稳定 ID 关联现有知识 / 能力节点。新增细粒度学习目标时，只更新明确版本的映射，不重写原测评快照。诊断卡可在后台表现为小型有向图，但第一版无需向学生再展示一张题内图。

图谱第一阶段只增加“本题自述 / 微任务观察 / 待核实”证据入口。后续同一困难在多道不同情境题中出现、且有相反证据对照时，才能提出“条件转译”“受力建模”等候选区域。同题重复、同一大题多个小问共享原因不得增加独立证据数。

一个未会的微任务不能沿关系边给所有相邻知识点上薄弱颜色。错因与能力也不是一一对应；“读漏条件”可能由文本理解、图像辨识、当时未完成或注意疏漏造成。素养要素只显示有依据的活动表现，不从单题推断科学态度与责任。

## 6. 最小数据与状态约定

建议新增，名称可在实现时依仓库规范调整：

- `question_diagnostic_cards`：学校、题目内容版本 / snapshot 内容指纹、父题与小问 key、卡片版本、诊断动作、目标引用、微任务及判定规则、可接受其他方法、提示、适用条件、审核状态、来源、模型 / prompt 版本。
- `wrong_diagnosis_sessions`：学生、错误来源类型（考试 / 个人试做）、不可变来源事件 ID、题目版本、被诊断小问、卡片版本、状态、首次显示及提交时间、分析版本。
- `wrong_diagnosis_events`：自述、微任务响应、帮助暴露、结果、更正与退出，保留顺序和幂等请求键。已给学生展示的卡片版本不可被后台新生成覆盖。
- `student_diagnosis_findings`：最多一个主要、一个次要候选，允许无法判断；支持 / 相反证据事件 ID、证据类型、后续动作、节点映射版本。不把这些结论直接写成教师确认的 `wrong_question_error_tags`。

状态包括：`offered → started → completed / inconclusive / skipped`，未开始不计失败。来源撤销则失效并停止用于汇总；内容关键更正可标为需重新评估，不能悄悄替换历史结论。

首次触发以服务器校验的学生 + 来源错误事件 + 题目版本为基础，整道大题另有一次展示约束。该大题首次只选一个最需要排查的小问；已经完成或跳过不因刷新、跨设备或随后点其他小问而反复提示。后续新增错小问只提供主动入口。用户主动重诊保留为另一会话，不抹掉初次诊断。

试做和考试来源必须经过各自权限链校验；GET 读取不能伪造完成记录。并发标签页与重复请求不能重复创建诊断或重复付费。

诊断事件独立于重做：不覆盖 `initial_answer`，不增加 `redo_attempts` 次数，不推进三次间隔复习。提示 / 答案暴露通过服务端事件记录；后续原题作答标注是否接受过帮助、是否自评及来源，不能只看 `purpose='verify'` 判断证据强弱。

现有 `learning_views` 只保存较粗的答案查看时间，不足以回放本次诊断中的提示、卡片版本和事件顺序，不能独自承担新增诊断证据。

| 诊断卡审核 | 初期仅使用教师审核通过的卡；模型自报高置信度不能代替物理审核 |

**预生成**：题目内容、答案与解析已核对后异步生成草稿，失败不阻塞入库、建考或学生查看题目。审核可批量进行，先做高频错题小样本。题目缺图、答案未确认或内容冲突时不生成自动判断路径，仍允许通用自我回顾。

**实时判读**：确定性选项优先本地判定。LLM 仅处理可选短句、可接受的其他解法或边界情况，从本卡允许的候选中返回解释与证据引用；允许 `insufficient_evidence`。不生成新的知识点、不把历史画像强塞成本次原因、不连续追问。

缓存身份：学校、内容指纹、小问范围、卡片版本、分类 / 图谱版本、提示版本、模型配置及参数共同决定题目卡缓存；个人响应还必须包含学生、会话、当前事件和帮助暴露状态。个人诊断不能跨学生共享。教师改卡或学生跳过后，迟到模型响应不能重新打开界面或覆盖更新。

只向被配置的服务发送诊断必要的题目与当前响应，不发送姓名、班级名、完整历史画像和整张答题卡；日志不存密钥。超时、配额耗尽或服务失效时退回审核卡 / 通用回顾，不把规则降级输出伪称模型诊断。

模型验收需要“真实题目 → 生成结构 → 校验 → 页面微任务 → 保存证据”的端到端烟测。现有“检查配置”只检查本地密钥和预算条件，不证明远端模型可用。首期不需要 LLM 长期总结，先生成可追溯的统计和教师证据列表。

| 验证成本 | 可先从小样本建立基线 | 不以问诊完成率或模型置信度证明学习效果 |

## 9. 分阶段交付与停止条件

1. **最小试点**：约 10—20 道高频力学错题、一班；教师审核诊断卡、两次操作、一次可选重试、独立证据存储、现有节点引用。模型不是学生必经依赖。
2. **可选 AI 增强**：管理员按用途配置生成与判读；增加后台任务、端到端烟测、额度与超时回退；与规则 / 教师卡对照实际收益。
3. **图谱消费证据**：个人局部图显示本题观察，再逐步加入跨题候选区域；新情境表现足够时才评价是否改善。

主要验收：

- 同一新错题不重复提示，整题分组不会出现多个强制问诊；已有答案暴露有清晰标识。
- 通常两次操作结束；可选帮助最多一次；没有结论也可正常继续。
- 学生可以否定系统解释，系统允许保留无法判断；不强行填满标签。
- 新诊断不改变首次答案、题目快照、原错题状态和复习次数；取消来源后结论不再有效。
- 共享模型配置按用途路由；暂停问诊不会影响标签生成、解析或现有重做。
- 对多解法、题目图示缺失、只导入得分、待复核、网络失败、跳过后迟到响应、并发重复提交和跨学生请求做针对性检查。
- 浏览器验收覆盖实际学生账号、手机 / 平板，以及新增表的备份恢复；行为上线仍需仓库远端 release check。

试点观察：完成用时分布（目标大多 30—60 秒）、跳过 / 放弃比例、学生认为建议有用的比例、教师对证据支撑与物理正确性的抽查、后续不同题独立表现。必须同时记录学生构成和样本量，不能把相关性当成诊断带来的因果效果。

停止 / 回退：发现错误物理规则或未审核答案泄露，立即停用对应诊断卡并保留审计；问诊阻碍正常复习或明显增加退出，回退为主动入口并减步骤；模型延迟 / 预算异常则停实时判读。以上阈值在试点前与教师确定，不在数据出来后调整以宣称成功。

当前不做：十五项强制分类、开放式长聊天、五级强制提示、根据一次问诊形成固定学生能力画像、自动刷新历史掌握度、全学科一次性铺开。

最终决定仍为本地化重建；架构和项目接入点已核验，教学有效性、完整 D 分类及真实模型表现待补证据。本轮交付是设计文档，没有部署诊断功能。
