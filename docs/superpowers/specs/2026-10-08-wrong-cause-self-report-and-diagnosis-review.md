# 错题自选错因与诊断设计复核

日期：2026-10-08。范围：当前代码、线上诊断卡内容与独立测试环境中的学生流程。下文的重构方案是建议，尚未实施；本次实施的是错题本自选错因。

## 本次交付

错题本的每张整题卡片下增加“我认为的失分原因”。常见原因直接显示为可多选按钮，点选保存、再次点选取消；“还不确定”与具体原因互斥。刷新后保留。复习队列、单题重做页、题库和历史测试页不显示这组按钮。

原因覆盖知识遗忘、概念理解、知识调用、条件遗漏、条件转译、模型识别、步骤衔接、公式应用、计算符号单位、看错抄错数据、答题表达、结果检查、时间不足、遗漏作答以及不确定。

记录属于学生自我判断。`student_wrong_cause_events` 独立保存每次选择及取消，绑定学生、学校、整题的错误来源和题目快照；同一大题的标记不自动解释为每个小问都存在该原因。原始作答、教师错因标签、诊断结论与掌握度保持各自的证据来源。请求幂等，旧页面不能覆盖另一页面的新标记；来源换新后不沿用旧标签。

## 结论

当前系统能帮助学生回顾、表达与整理错因，也能找出本次某个小检查没有通过。它尚不足以稳定地区分“知识遗忘、知识调用、条件解码、模型或步骤组织”等原因，更不能据此还原考试时的真实思维全过程。

主要差距在诊断内容和分支判别，不在按钮数量或模型参数。接入更强的模型不会自动弥补这些缺口。

## 当前实现的直接证据

1. 线上 23 张诊断卡，共 92 个检查点；全部是每卡四步、每步两个选项。第一层提示只有四种通用文案。该统计只描述当前内容，没有准确率含义。
2. “α 粒子是什么？”被标为 `condition`；“加热放射性物质是否改变半衰期？”被标为 `execution`。这两项分别检查基础知识与规律理解，不能直接证明条件解码或计算执行能力出了问题。来源：线上 `diagnostic_cards.card_json`，本次只读抽查。
3. `diagnosis_reasoning.py` 中，粗略流程按学生最初自述跳到对应阶段，取一至两个检查；精细流程遍历全卡。两者使用同一组检查，主要区别是覆盖数量。
4. 最终原因主要取自一次 `locate` / `revise` 选择。检查是否通过、提示前后表现用于补充或提示矛盾，尚未对多数相邻原因执行真正的排除性追问。
5. 弱提示固定按阶段给，强提示通常就是解释。收到解释后答对可以证明这次借助帮助推进了，不能直接证明最初失败是知识调用不足。
6. 选择题当前答对只能说明本次选中了合理答案。没有足够依据将它推成“此前知识已经熟练”“考试时只是没想到”或“整个知识区域都薄弱”。

上述是实现与内容审查，尚无教师核对的真实学生诊断样本，不能报告诊断准确率或教学效果。

## 从目标重新设计

目标应当是让学生获得三个清楚的答案：这道题的哪个必要动作卡住了；目前更支持哪种原因、还不能排除什么；下一步用什么小练习验证和改善。

### 三条学生路径

| 学生情况 | 路径 | 应交付的结果 |
| --- | --- | --- |
| 我已经知道原因 | 错题本直接点选，本次已实施 | 学生自述原因，可更正、多选 |
| 我大致知道卡在哪，但不确定为什么 | 粗略诊断，围绕一处困难提问 | 一个待验证的原因候选与一条建议 |
| 我说不清，或粗略结果不符合 | 精细诊断，自适应追问 | 最先受阻的必要动作、区分相邻错因的证据、明确剩余不确定性 |

粗略与精细应区别在判别深度。精细不要求每个人机械地做完所有环节；已经能排除某类原因就跳过，达到足够定位依据就停止。仍然全程点选，可以退出。

### 每道题先建立真实的解题动作图

按本题实际过程确定研究对象、条件转译、模型选择、规律及适用条件、关系连接、计算、表达与检验。允许多条合理路径，并标出各动作的前提。知识概念检查不强行贴成“条件理解”，规律判断不强行贴成“计算”。

为每个易卡动作准备：一个检查、能排除相邻错因的追问、不会直接泄露答案的最小提示，以及一个不照抄原解释的验证选择。现有卡片需逐题审查，不应仅将通用提示文案换一遍。

### 用可区分的表现支持原因候选

| 候选原因 | 需要补充的证据 | 仍然不能据此断言 |
| --- | --- | --- |
| 知识遗忘或概念不清 | 直接的概念、规律含义和适用条件检查；分别记录识别与理解 | 一次选错不能区分长期没理解和暂时没想起 |
| 知识记得但没有调用 | 基础知识检查通过；在题目中自行选规律受阻；最小线索后能完成另一处应用选择 | 被直接告知答案后选对，不能支持该原因 |
| 条件没有转译 | 基础概念能辨认，但无法把本题语句转为约束、状态或物理关系；针对性提示后变化 | 漏读是对原作答的回顾，需要与当前检查分开记录 |
| 模型识别 | 能解释关键条件和基础规律，但研究对象或模型选择不当 | 如果前置条件都未理解，不能把模型问题当独立主因 |
| 步骤组织 | 能判断各条规律的含义和适用性，却无法连接中间量或判断先后步骤 | 不会某条规律时，不能只归为思路组织 |
| 计算或表达 | 能选择合理模型和关系；具体符号、单位、计算步骤或理由完整性检查发现差异 | 没有原过程时，不能确认考试当时具体在哪行出错 |

示例：不能仅问“你是忘了牛顿第二定律，还是没想到用”。可以依次检查对合力与加速度关系的理解、在本题中选择研究对象及适用关系，再看一个最小提示是否帮助学生完成新的关系判断。结果写明“本次基础关系检查通过，应用线索仍需练习”，并将“原来没想到”保留为学生回顾。

### 结果应能指导下一步

结果页呈现“本次卡住的动作 → 支持的原因候选 → 判断依据 → 一项针对性练习 → 独立再检查”。例如，知识调用练习只判断该用什么规律；条件转译练习只选出一句条件对应的物理关系；步骤组织练习只选择合理的中间量和先后顺序。

保留学生自述、检查表现、提示暴露、系统推断、学生更正五类来源。一次诊断先服务这一题，多题与后续独立练习出现一致表现后，再考虑知识区域层面的归纳。当前图谱入口继续维持关闭。

## 建议实施顺序及验收

1. 校正现有 23 张卡的动作归类，明确哪些检查真正能区分原因。先解决上述阶段错配与通用提示问题。
2. 将粗略与精细改为不同深度的分支判别；让“说不清”、矛盾结果和提前退出都有合理结果，避免强制归因。
3. 给结论接上相应的小练习与不带提示的后续验证。
4. 用成对案例检查：同样答错但实际原因不同，是否会走不同追问并产生不同的证据说明；由教师复核学生样本，统计误归因与无法判断，再讨论实际教学效果。

本次验证覆盖学生自选原因的保存、取消、多选、未知互斥、幂等、并发冲突、权限、来源隔离、个人错题、原证据不变与页面范围。它证明功能行为，不证明诊断准确率。
