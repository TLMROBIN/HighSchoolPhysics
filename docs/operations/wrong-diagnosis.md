# 错题思维诊断

所有学生的已发布错题及个人错题默认出现“先找找思维卡点”。学生选择小问，回想首次作答的卡点（可记录一句思路），再选择快速或深入模式。快速检查最接近自我判断的 1—2 步，深入检查 3—6 步。可逐级请求提示、结束、从快速转深入；刷新保留进度。

管理员进入管理页面的模型与服务配置，找到“错题思维诊断模型”，填写 Base URL、API Key 和模型名，保存后后台处理缺少卡片的题目。使用 OpenAI 兼容 Chat Completions。更换模型时密钥留空可保留。点击“实际生成测试诊断卡”会真实调用一次模型并校验结构；不表示教学内容已经人工审核。默认每天最多 1000 次调用，沿用服务调用审计与加密密钥存储。不要把密钥写入文档、命令行或提交。

文档工作进程在导入、扫描及标签任务之间继续处理诊断队列。没有配置时显示待配置，学生可正常重做；网络或输出失败最多重试三次，管理员再次保存配置可重试。结构校验通过的模型卡供学生做思维检查，不作自动成绩或确定性知识掌握判定。模型仅收到题目文本、对应小问及已有解析；图片读数无法确认时要求生成不依赖读数的概念检查，不发送学生身份、答卷或诊断记录。

卡片按题目内容指纹保存，也为历史测试内容准备对应版本。当前题目修改不会把新卡套到旧答卷。当前人工补齐包包含 23 个小问、92 个检查点；它只适用于指纹匹配的内容。部署前保存 SQLite 备份，再运行：

```bash
python3 -m highschoolphysics.diagnosis --db data/school.sqlite3 --backfill
```

运行输出 covered=23、skipped=0 才代表当前补齐包全部匹配。后台会另外准备新版本。诊断事件与 `student_responses`、`redo_attempts` 分开保存；诊断检查不产生重做成绩。提示或检查反馈视为帮助，当天接着重做记作 `purpose=learn`，独立复习另行验证。原答卷、教师确认状态与历史未知帮助证据不会改写。自我定位、检查结果与学生最后确认分别保留，可供后续知识图谱按题目 ID 和已有三类标签关联。

验证覆盖：权限隔离、卡片版本匹配、提示梯度、幂等提交、刷新恢复、快速转深入、模型故障、配置密钥不泄漏、学习练习不增加独立验证次数。上线验收需另查实际学生页面与部署服务，不以本机测试替代。
