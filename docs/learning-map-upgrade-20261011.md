# 学习地图升级与判读口径

学生入口：`/physics/app`（默认学习地图）、`/physics/app?module=graph`。
教师入口：`/physics/teacher?module=regions`；共同目标审核仍在 `module=graph`。

## 使用流程

学生先看最多三个值得处理的内容区域。卡片保留首次答错、答对、空白和待确认数量，提供补查、练习或到期复查入口。每次建议只导航，不创建练习或修改掌握状态。小问入口携带对应的诊断题目，避免打开同一大题中的其他小问。

目录保留全部有效教材区域，明确区分尚未观察、有首次答对证据和需要补查。原始依据逐层展开；知识关系图作为次级入口。学生首页筛选默认折叠，并显示当前记录范围。

教师选择授权班级、时间范围和测评，查看内容区域与概念理解、对象与条件、规律与列式、计算与检查的矩阵，点击后查看学生分组和依据。仅统计该班在读学生、授权且已发布测评的在场作答。无记录、空白和待确认不按错误或零分推断。缺少有效标签的记录明确提示尚未归区。

## 证据规则

- 考试标签只定位题目涉及的内容，不把一次错误分摊给全部标签，也不据此判断具体学习环节。
- 首次作答统计按独立任务去重；同一内容组的小问、题目修订版本和重复检查不增加独立任务数量。
- 首次无提示检查、受帮助的练习、说不清和延迟复查分别保存。练习完成不会直接变成独立通过。
- 反复受阻须在同一个已确认具体目标上有至少两个不同任务的无提示失败。状态和数量分别显示；既有通过与失败并存时显示表现不一致。一次通过只称检查通过，不称整题或区域掌握。
- 班级矩阵按学生去重。具体环节的分母要求同一目标有至少两个不同任务的该环节检查；证据不足人数单列。阶段详情与矩阵采用相同的阶段证据。
- 跨内容区域只合并教师逐项确认的共同目标，并只在实际出现观察的区域显示，不沿图谱推断相邻知识薄弱。
- 首次检查与另题复查的目标对应、所属内容和学习环节须分别审核。有些复查测的是相关能力，不能自动认定与原检查相同。

规则版本 `learning-regions-v1`。页面显示图谱版本和本次证据指纹，包含班级、学生范围、测评范围、图谱版本和输入记录。

## 目标审核与历史版本

新增目录为 23 张现有精确内容版本的诊断卡提供 91 个动作对应候选。候选不自动成为教师确认结果。目录安装只在诊断卡指纹及分支内容哈希同时匹配时追加不可变图谱版本；启动重复执行不追加相同映射。

教师展开“共同学习目标审核”，核对实际首次检查或另题复查的题面与正确选择，选已有目标或明确新建目标，选择所属知识和学习环节，再点击确认。保存受学校范围、版本冲突和有效目标检查保护。

新会话冻结目标、定义、条件、审核状态和图谱版本。随后审核不改写既有会话；已经固定的空映射 `[]` 不补映射。升级前 NULL 映射仅按完全匹配旧卡的首个历史发布恢复只读显示，仍标为待确认，不追认历史跨题聚合资格。

手动移出错题本后，首次作答和历史诊断依据仍在地图中保留；来源链接指向已发布测评，避免跳到已失效的错题重做入口。

## 验证边界

新增测试覆盖目标精确匹配与幂等安装、教师审核及旧会话冻结、NULL/空映射兼容、帮助与未知选择、跨区域及跨阶段统计、父题小问去重、历史保留、授权班级/学生边界和代理路径 HTTP 页面。

隔离演示数据库通过实际 Chromium 检查 1440、390、320px 学生/教师页面、筛选、证据展开、名单下钻和显式目标保存。六个页面无整页横向溢出或 JavaScript 错误；图像及报告在本地 `.impeccable/review/learning-map-20261011/`，不作为生产数据或课堂验收。

设计独立审阅提出的四项修正均已解决，结论范围仅为该批修正。现有 DESIGN.md 与设计 sidecar 保留；既有顶栏在320px逐字换行、全局题卡12px圆角与文档8px差异未在本轮重做。

发布前备份完整数据库并记录受保护证据表摘要；发布后核对摘要，确认原始作答、评分决定、答题卡证据和已有诊断未被升级改写。远端验收采用 `REQUIRE_REMOTE_HEAD_MATCH=1 bash scripts/hsp_release_check.sh`。

本次没有模拟生产学生检查记录。实际阶段矩阵需要教师审核对应关系并逐步积累学生检查证据；证据不足时如实显示，不能把缺少检查误称为没有问题。
