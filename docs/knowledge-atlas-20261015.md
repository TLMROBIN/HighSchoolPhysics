# 知识图谱浏览改版

## 目的与范围

图谱首页按“教材 → 章节 → 知识点 → 关系与依据”展开。用户确认以教材知识地图为默认浏览方式。教师的“诊断与知识图谱”入口先展示可交互地图，原诊断卡与关系审核保留在独立展开区；携带 `card` 或 `edge` 的审核链接自动展开编辑区。

学生显式 `app?module=graph` 页面复用地图，学习证据与待处理区域按需展开。学生默认错题本、隐藏学习地图导航的既有决定继续保留。

## 浏览方式

- 按教材顺序切换当前启用教材；默认目录包含六册，校本教材和节点从当前启用目录读取，不硬编码内容。600px 及以下使用带“教材”标签的原生选择框，减少手机首屏的控件占用。
- 搜索名称、说明，按知识、学习目标、能力、素养筛选。搜索结果显示完整层级，点击后才改变中心节点；无结果可清空。结果较多时可继续显示。
- 图谱保持稳定的分层位置。桌面显示中心与相邻分支，小屏使用纵向图；长名称换行，完整名称可从详情及列表读取。SVG 高度随显示的节点行数增长，进入或复位时不再由固定高度画布裁掉首尾节点；页面原生滚动承载完整图谱。
- 面包屑、教材概览、浏览器前进/后退可以返回；URL 保留当前中心与教材。
- 图谱与列表可以切换，缩放可复位；相邻节点多于首批时可以继续展开，列表包含全部直接邻居。
- 点击连线或“查看依据”读取关系方向、确认状态、适用条件和来源。目录关系不表示前置条件。节点类型同时有形状和文字，确认状态同时有虚实线及文字。
- 手机端有“查看详情 / 回到图谱”定位，工作台导航默认折叠；触控滚动使用浏览器原生行为，系统减少动态效果设置得到尊重。
- 键盘激活教材、搜索结果、面包屑或节点链接后，图模式把焦点交给所选节点，列表模式交给稳定的详情区；关系详情替换后也保留连续的操作位置。所选 SVG 节点以琥珀色描边显示键盘焦点，原生教材选择框保留自身焦点。

## 视觉约定

继续使用现有课堂界面的白色纸面、冷灰画布、松绿操作色和系统中文字体。能力蓝、素养紫及目标琥珀仅区分节点类型，并同时搭配形状与文字；关系确认状态仍有文字、线型和来源说明。局部语义配色、响应式布局与焦点行为记录在 `.impeccable/surfaces/highschoolphysics-assets-learning-graph-js.md`，不扩展为全系统新规范。

`PRODUCT.md`、`DESIGN.md` 和 `.impeccable/design.json` 保持原样。根设计文档与侧车中仍有“学生四个导航模块”的旧描述；当前代码已经按既有用户决定隐藏学习地图入口，本次继续保留该行为。

## 数据与权限

共用课程结构读取不含学生证据。学生观察仍按当前学生单独读取；教师浏览不获取全班个人诊断记录。草稿、已排除关系与节点不进入浏览图。浏览不修改首次作答、历史快照、诊断记录或图谱发布版本。

新增测试覆盖共用结构不携带个人诊断、学校隔离、已排除目标/映射过滤，以及教师浏览和审核的分层。
