# 首次导入执行与实际使用

> 2026-09-22 更新：下文保留为原方案/导入历史。当前实施已改为不记录分数的错题系统，操作与规则以 [三阶段升级及使用指南](07-outcome-upgrade-and-guide.md) 为准。
更新：2026-09-22。本文接续前五份设计文档；最终发布数量以部署验收回执为准。

## 本次范围

- 13、14班，相邻两张扫描按用户确认对应同一学生；正面识别、反面留在原始材料中。
- 原题1—10共46分；11的三个填空6分；12的四个文字填空8分。共17个评分项、60分。
- 12(2)电路图仅作为题目上下文保留，不判分；13—15解答题、计算题不导入。
- 多选完全正确6分，非空正确子集3分，含错误选项或空白0分。实验填空按原图核对等价含义；12(4)接受0.27—0.31W。
- 原题1末句A修正为C；原答案中多余11(3)不建题；第9题解析选项次序已校正。
- 本次不推断“概念不清”等原因；只按逐项作答结果关联已有知识点和能力标签。

## 管理员现在怎么用

1. 统一平台登录后，点击顶部 **考试与作答**。
2. 打开相应班级的“高三第一次周测”。“学生与总分”显示本范围得分、纳入状态及逐题记录数。
3. 下方逐题显示原题图、标准答案、解析、知识点及能力标签。展开“查看全班本题作答”可查看每个学生的实际答案、得分及答题原图。
4. 核对异常时，以原图和评分依据为准；同批次重新上传不会增加重复考试，内容改变也不会覆盖已发布成绩，应使用既有成绩修订流程并记录理由。
5. 未纳入学生不生成零分、不生成本次错题。

## 学生怎么用

1. 通过统一登录进入，点击“考试与作答”，只看到自己已发布的考试。
2. 查看自己的分项得分及作答依据；从“去错题本”进入错题列表。
3. 错题可打开完整原题图、标准答案与解析，查看知识点、能力标签；“我的答题原图”只向本人及有权限的教师/管理员开放。
4. “去独立重做”隐藏答案，支持单选、多选及文字填空。提交后等待教师复核；失败仍保留在待重做。
5. 同题累计3次经复核完全正确后才显示“本题已掌握”；一旦新的重做仍错，重新进入需巩固。自评“我觉得会了”与核验记录分开。重复复核同一次作答不增加次数。

## 后续考试怎么导入

保留试题、标准答案、评分说明和按学生组织的扫描原件；限定选择题、文字填空。先按名单核对身份，再按题号整理作答与原图，确认标签和等价评分，输出 `hsp-exam-v1` 整理包。在“考试与作答”选择JSON文件，点击“检查导入内容”，核对人数、评分项、满分和未纳入名单，最后“导入并发布”。

目前不是把任意PDF上传就能无复核自动判卷。本次完成了材料整理与视觉核对，并补齐已核对资料的正式导入能力；未来视觉AI可接入上游整理与待复核环节。现阶段不把OCR置信度当成答案正确率。

上传分块处理，适配现有网关单次1MB限制；整理包上限64MB，题图/作答图PNG单张8MB。上传暂存按账号隔离，新上传时清理超过24小时的暂存；正式发布数据独立保存。发布前检验所有纳入学生的全部题号覆盖，并在同一事务中建立题目、测评、成绩、错题及图片，失败全部回滚。

## 统计解释与后续边界

本次考试正确率只描述本次成绩；后续每次经复核重做都计入练习表现，不把反复错误去重掉。标签错误率分母使用实际作答中具有该标签的题次，不再用“全体学生×整卷题数”。标签表现是历史作答证据，不是细分能力病因。

当前“三次”按三次独立提交并经复核计数，尚未强制跨日。间隔学习、跨日提醒、例题与练习交替、变式练习和AI视觉批改仍属后续阶段，未在此次导入中宣称完成。

## 本次修复的运行问题

- 学生与管理员历史上被同步进不同的学校记录：基于备份合并同校归属，保留所有账号ID；不放宽跨校图片权限。
- 默认知识体系尚处草稿：核对现有标签后发布，导入预览对未发布体系给出明确提示。
- 统一登录仍继承本地临时密码标记：只有通过验证的SSO回调才清除此标记，密码生命周期交由统一平台负责。
- 扫描导入发布完整性、幂等保护、实验等价分数记录、多选部分分、错题原图、管理员逐题查看、多选重做控件及复核/掌握区分。

实际学生资料、扫描、逐题整理表及数据库备份均放在项目忽略目录 `references/weekly-test-20260922/` 或服务器 `data/import-backups/`，不进入代码仓库。

同一时间的统一目录更新可能先把新生升到“高三13班”，原有学生班级名称尚是“高二13”。这类历史班级别名冲突用**管理员明确补充本次参测名单**解决：必须指定学生ID、姓名、当前班级ID及原因，预览公开显示说明；不改回统一身份，不允许教师隐式跨班导入。考试参测名单固定保存，之后正常转班不会丢失本次考试记录。
