# 反馈评估与规则建议

## 1. 对本次范围调整的判断

保留“题目对错 → 知识/能力关联统计”适合当前原型。它可解释、教师额外工作少，也便于从一次真实周测开始积累证据。上一轮建议把诊断、教学干预和产品成熟化同时展开，近期范围过宽，应收紧。

题目数量增加能够减少部分偶然性，但不能自动消除题目标签偏差、评分错误、重复练习占比过大等系统性影响。因此近期只补统计透明度和流程正确性，不增加细分判断任务。

| 本轮保留/实施方向 | 暂缓至未来 |
| --- | --- |
| 教师确认题目标签；依题目结果关联知识和能力 | 概念不清/适用条件不明等自动归因；探测题 |
| 原题错题本、答案解析、重复练习、轻量复习排期 | 自动变式、陌生情境验证、个性化补救资源推荐 |
| 历次对错记录、三次间隔正确的本题巩固规则 | 基于手写步骤的规则化能力推断、复杂诊断模型 |
| 整卷与逐题得分的可靠导入、常规表单与待办队列 | 完整视觉 AI 阅卷、跨系统问答与仿真联动 |
| 保留现有图谱和关联浏览 | 新建大规模先修关系与因果诊断 |

未来视觉 AI 可同时读取题干、图形、手写过程与评分标准，提出评分和诊断建议；模糊、矛盾或无法判断的样本仍需复核。AI 阅卷与细分诊断另立升级，不作为本轮首次使用的依赖。

## 2. 当前“题目分析”到底做什么

实际调用是 `PhysicsRepository.generate_llm_candidates()` → `llm.generate_candidate_tags()`。尽管页面写“LLM 候选审核”，该路径标明 `MODEL_VERSION = rules-only`，当前不调用远程语言或视觉模型。

输入主要是题干、章节、解析、情境描述；对照知识节点名称/别名及能力、素养关键词规则生成候选，再由教师确认。没有强匹配时还可能返回第一个标签作为低置信候选，不能视为可信自动分类。

它的用途是给题目建立目录关系：一旦学生该题做错，错题本、图谱、相关题导航和教师统计便知道关联哪些知识与能力。它不读取学生完整手写过程，也不判断具体错因，更不等于自动阅卷。

导入包括三个不同工作：

1. **试题整理**：把试题、答案、分值、图形与题号整理成题目记录。
2. **题目归类**：给一道题选知识/能力标签；同一道题通常只需教师确认一次，全班共用。
3. **学生作答与评分导入**：把每个学生、每题、答案/得分与扫描原件对应起来。

建议第一轮不强制 AI。教师可直接选择少量标签，规则候选仅作辅助。若加入 AI，优先帮助整理试卷和建议标签，收益按题计算，不必让教师逐人做诊断；图文复杂题可由视觉模型读原题，结果仍需确认。AI 不可用时人工标签入口照常工作。

重要实现细节：现有题目/评分/标签快照在 **创建测评时** 写入，因此答案、分值、题型、标签应先确认，再创建测评。不能承诺创建测评后改题库即可自动改变该次测评。

## 3. 重复作答如何计数

修正上一轮“每道题只计一次”的笼统建议：每次真实、已判定的正式作答都应保留并参与练习统计。需要去重的是网络重试、双击提交或同一记录的重复复核，不是学生新的真实尝试。

原型继续使用易解释的口径：

`本题练习正确率 = 本题正确次数 ÷ 本题有效作答次数`

`标签练习正确率 = 关联该标签的正确次数 ÷ 关联该标签的有效作答次数`

有效作答包括已发布测评结果及已确认的正式重做；原测和重做在明细中分开。待判分、识别不清、漏扫、缺考不作为错误；确认参加考试且该题留白才计入作答总数，并单列空白。

| 本题经历 | 正确/有效次数 | 历史练习正确率 |
| --- | --- | --- |
| 原测错，之后三次对 | 3/4 | 75% |
| 原测错，之后两次错、三次对 | 3/6 | 50% |
| 上一行基础上再错一次 | 3/7 | 42.9% |

这满足“反复做不对也应影响正确率”。若此前正确数就是 0，继续错误仍为 0%，但错误次数会继续增加。重做不会改写原测评分数或本次班级测评错误率。

代价是高频重做的题会占标签统计较大权重。这一版先不引入加权模型，而是把标签百分比准确命名为“关联题练习正确率”，同时显示“涉及几道不同题、原测几次、重做几次”，供教师理解来源。可展开查看“仅测评”与“重做”两个部分，避免把刷过一题十次说成练过十道题。

同一作答对同一个标签只能计一次；一道题有多个不同标签则分别贡献给各标签。全卷总数不能把各标签分母相加。同题同标签即使元数据重复也须先去重。按测评快照归属，不随以后题库重打标签漂移。

## 4. “至少重新做对三次”怎么落地

建议用于 **曾做错题目的巩固状态**，不要求所有初测正确题一律强制重做三次。初测答对展示“本次正确”，不直接推断某知识点“已掌握”。

推荐规则草案：最近一次正式错误之后，累计三个按排期完成的独立正确验证，标记“本题已巩固（3/3）”。三次应间隔完成；中间正式作答再错则该题进度回到 0/3，历史记录和百分比全部保留。连续正确比终身累计三次更能防止“此前对过三次，最近又错仍显示掌握”。这是待采用的产品规则，不是已获验证的认知阈值。

初始排期建议：错误反馈后第 1 天开始第一次验证；第一次通过后间隔 3 天；第二次通过后间隔 7 天。以上是距上一个节点的间隔，不是同一基准的第 1/3/7 天。失败后下一天再安排；逾期顺延，不累计多个过期副本，不惩罚。

计数细则：

- 每次正式、已确认的独立提交都进入对错统计；同日额外正确不会多推进一次排期间隔。
- 正式错误会重置进度并重新排期；待复核不推进也不提前清零。
- 看解析/例题后的学习练习不算独立验证，不据此推进 3/3；界面从练习入口就区分用途，无需教师新增错因判断。
- 按提交时间判定是否到期；复核时间仅决定结果何时生效，不把教师晚批几天当作学生间隔复习。
- 建议每题同时只允许一个未复核提交。乱序复核或分数修订按作答时间重算派生状态，不按最后点击的顺序覆盖。
- 同题已巩固后若在后续正式作答中再错，重新进入复习；同一原题跨测评使用稳定题目标识管理进度，原测证据仍各自保留。题意或评分实质变更应视作新题，不沿用旧进度。

“本题已巩固”和“历史正确率 50%”可以并存：前者表示最近三个间隔验证通过，后者表示过去确实错过多次。界面不要用一个词混合这两层含义。知识/能力图谱显示关联题表现与待巩固题数，不再由一次答对自动给出“已掌握”结论。

工作量风险：一道错题至少三次验证会增加练习量，尤其主观题。默认每天少量到期题，教师可设数量上限；单选、多选和适合规则评分的填空题自动确认，主观题人工复核。不要默认把整个错题本一次性全部布置，也不要要求教师每次填写诊断分析。

## 5. 错题学习四种表现如何裁剪

| 表现 | 原型处理 |
| --- | --- |
| 看过解析/例题 | 记学习行为，可选“我看懂了”自评；不增加正确次数 |
| 独立重做正确 | 保留正式作答与评分，展示本次结果 |
| 陌生变式也会做 | 本轮暂不要求，不设置空任务，不靠原题重做冒充迁移 |
| 隔一段时间仍做对 | 用同一题的轻量排期验证；明确只能证明该题的保持表现 |

“例题与独立练习交替”只在有现成、教师认可的示范题时启用人工关联；没有配套题就提供原题解析与隔日独立重做，不自动生成一套新题。看当前题完整答案后马上做同题，只算学习练习。

研究支持间隔学习、主动提取、例题与独立练习交替的大方向，但不证明三次或 1/3/7 天对所有学生最优。依据：[IES/WWC, Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)，2026-09-22 重新读取，指南发布于 2007 年。

## 6. 教师诊断百分比

本次测评与历次练习使用不同统计范围：

- **相关作答错误率**：本次标签下非空错误作答数/有效作答数。
- **空白率**：确认空白作答数/有效作答数。
- **出现错误或空白的学生占比**：出现至少一次上述情况的去重学生数/该标签有有效作答的去重学生数。
- **历次练习正确率**：关联题所有已确认正式尝试，含重做，用于学习页面；不混入本次考试报表。

缺考、漏扫、待复核属于数据完整性提示，不填成 0 分。零分母显示“暂无有效数据”。主观题部分得分在本轮仍按“未完全答对”关联，保留实际分数，但不推断哪个能力步骤有问题。
