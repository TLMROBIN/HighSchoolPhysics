# 学习地图易用性与视觉复核

在已有学习地图上保留“安静的物理解题桌”，优化学生下一步与教师班级定位，不改变学情判断规则。

## 操作变化

- 学生首页缩小关注设置、待复习入口和模块导航；每个重点区域先给出下一步，判断依据按需展开。
- 教材目录默认折叠，有记录的教材优先，同组按稳定教材编码排序。搜索章节、下级知识点或已有具体目标，匹配结果自动展开；无结果提示可清空搜索。
- 学生所选区域依据位于目录之前，教师所选区域名单位于长表格之前；提供返回目录或班级分布入口，保留班级、时间范围及测评参数。
- 教师窄屏默认只看首次作答线索，可切换四个学习环节或全部对照。完整表格可横向滚动并固定区域名称。
- 教师小屏次要模块导航折叠，统计口径按需展开，当前时间及测评范围持续显示。更换班级时清空旧班级测评选择；仍需点击“更新视图”。默认选有在读学生的授权班级，明确选空班仍显示空班。
- 没有足够证据的区域显示“尚无足够检查”，不展示 `0 / 0`。账号栏在窄屏主动换行，避免名字、角色和退出逐字碎裂。

## 保留的边界

搜索、列选择、展开及 GET 页面均不写入学习记录。没有提示的独立任务、空白、待确认、无记录、练后待验证等既有含义保持不变。标签只能定位题目涉及的区域，不能直接判定具体知识薄弱。没有 JavaScript 时，教材目录和完整表格仍可使用。

## 验证证据

- 实际 Chromium 页面：学生与教师分别检查 1440、1024、768、390、320px；扩展夹具含 28 名合成学生和 3 个待处理区域。测试数据只在临时 SQLite 中，不进入部署数据。
- 操作检查：知识点搜索及清空、无匹配状态、键盘展开、时间筛选、单环节切换、名单和首次答案展开、教师明确确认目标对应。
- 概览截图、零分母截图和区域名单截图：`.impeccable/review/learning-map-usability-20261011/`；独立评审五项修复均判定 resolved，处置为 ship，仅覆盖该修复清单。
- 全量本地发布检查通过：548 项测试，1 项跳过；编译、JavaScript 语法、runtime readiness 与 diff 检查通过。新增地图脚本单独检查，并纳入以后的发布语法检查清单。
- 原生浏览器连接超时，使用独立的实际浏览器测试替代；本轮属于浏览器响应式验收，尚不能代表真实平板设备或课堂验收。
